# 赤ペン予想（競艇・機械学習版）

住之江を対象に、ボートレース公式が配布している番組表・競走成績を毎日取り込み、LightGBM で「各艇の1着率・3着内率」を学習します。
毎週学び直して、検証成績が基準を上回ったときだけ本番モデルを入れ替えます。予想は指示したときだけ PDF に出力します。

> この予想は統計モデルの推定で、的中や利益を保証しません。

## しくみ

| 段階 | 内容 |
|---|---|
| データ | 公式の番組表（B）と競走成績（K）を `www1.mbrace.or.jp` から日ごとに取得し、住之江の分だけを `data/boat/races/YYYY-MM.parquet` に保存 |
| 特徴量 | 枠・級別・全国/当地勝率・モーター/ボート2連率・今節成績、過去成績から作る「その枠での1着率」「平均ST」「最近の平均着順」、レース内の順位と平均との差。直前情報（展示タイム・風・波）は渡されたときだけ使う |
| 学習 | 直近56日の**住之江**のレースを検証用に取り分け（時系列で分割）。住之江のデータで3つの設定を試し、住之江での検証の対数損失が最小のものを選ぶ |
| 入れ替え | 「学習期間の住之江の枠別1着率だけ」の基準より良いときだけ、全データで学び直して `models/boat/` を更新。毎回の検証成績は `models/boat/history.jsonl` に残る |
| 答え合わせ | 出した予想は `predictions/boat/` に記録し、結果が出たら `models/boat/live.json` に実戦の的中率を集計 |
| PDF | 表紙（本命一覧・検証成績・実戦成績）＋1レース1ページ（印・1着率・3着内率・数字の根拠・3連単候補） |

## 自動で動くもの（GitHub Actions）

- **毎日のデータ更新と毎週の再学習**：毎日 1:00（日本時間）に直近7日分を取り込み、答え合わせ。月曜は再学習も行う。
  - 初回は「Run workflow」で `start` に `2023-01-01` などを入れて過去データを一括取得し、`train` にチェック。
- **予想PDFを作る**：「Run workflow」で日付・レース場・レース番号を入れると、PDF が成果物（Artifacts）として出る。
- **テスト**：push のたびに実行。

## 手元で使う

```
pip install -r requirements.txt
python -m akapen.cli boat-update --start 2023-01-01 --end 2026-10-20   # 過去データ取得
python -m akapen.cli boat-train                                       # 学習・検証
python -m akapen.cli boat-predict --date 2026-10-22 --venue 住之江 --race 1 2 12
python -m akapen.cli boat-score                                       # 実戦の答え合わせ
```

直前情報を使う場合は `--pre 直前情報.csv`（列：`venue,race_no,boat_no,exh_time,wind_speed,wave`）を渡します。

## 注意

- 公式サイトへの負担を避けるため、1ファイルごとに1秒空けて取得し、取得済みの日は再取得しません。
- 解析は公式の固定幅テキストの書式に合わせています。読めなかった行はログに件数が出るので、初回取得後に確認してください。
- テストは公式と同じ書式で作った**架空データ**で、取得〜PDFまで通ることを確かめるだけのものです。モデルの実力は、実データでの `history.jsonl` の検証成績で判断してください。
